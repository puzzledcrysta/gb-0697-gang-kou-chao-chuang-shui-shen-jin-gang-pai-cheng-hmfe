# 潮窗字段

id保持字符串。kind取tide、ship、pilot、block、exit_port、exit_pilot。start/end带时区；统一UTC秒。tide的value为潮高；ship为吃水；m/cm统一为m。ship的aux为通航分钟。version为递增版本，采用同ID最高版；同版多条隔离。潮位乱序按时间排序。

离道回执为点事件：exit_port是港调离道时间，exit_pilot是引航离道时间，只填start，value/aux留空。同一艘已排船两源回执到齐才核准释放；任一源缺失保持PENDING，航道不提前腾出。两源时间不一致时释放时刻取较晚者，并在台账标记mismatch，明确从何时起释放占用。找不到对应已排船的回执记ORPHAN。

候补递补（M8）：M5未能安排的船按申请时刻、ID排序进入候补。释放只裁剪来源船自身的占用区间，候补船仍须满足自身水深潮窗与引航窗口，采用最早可行窗，记录释放来源船。迟到的低版本回执按版本机制失效，不能撤回已核准释放；同输入同摘要重试复用批次，候补船只安排一次，状态为BACKFILLED。

基准水深8m，安全余量1m，要求潮高>=吃水+1-8。相邻潮位最长允许3小时插值；缺口不外推。航道区间为半开，结束同刻可开始下一航次。引航窗口须覆盖整个航次。排程按最早申请时间、船舶ID确定先后，采用最早可行窗。并非全局最优调度。

业务ID按kind命名空间隔离。同一UTC时刻的潮位不同值全部隔离为TIDE_TIME_CONFLICT，不能用其中任意值开启安全窗；同值重复仅保留编号最小者。

冲突潮位时刻保留为插值断点，相邻有效观测不能跨越该时刻推算安全窗。
